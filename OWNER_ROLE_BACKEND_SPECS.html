1. Executive Overview & Mental Model

The Company Owner (Avery Scott) operates at the 30,000-foot strategic layer of the construction enterprise. Unlike a Field Superintendent managing daily trade crews or a Project Manager handling RFIs and submittals, the Owner cares about portfolio solvency, bank draw status, risk containment, and overall capital protection.

4. Recommended Database Schema (PostgreSQL / Relational)

-- 1. Projects Master Table
CREATE TABLE projects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    city VARCHAR(100),
    state VARCHAR(50),
    status VARCHAR(50) NOT NULL DEFAULT 'In Progress',
    start_date DATE NOT NULL,
    target_end_date DATE NOT NULL,
    progress_percentage NUMERIC(5,2) DEFAULT 0.00
);

-- 2. Project Budgets & Contingencies
CREATE TABLE project_budgets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    total_budget NUMERIC(15,2) NOT NULL,
    committed_amount NUMERIC(15,2) DEFAULT 0.00,
    actual_spent_amount NUMERIC(15,2) DEFAULT 0.00,
    contingency_reserve NUMERIC(15,2) DEFAULT 0.00,
    currency VARCHAR(3) DEFAULT 'USD'
);

-- 3. CSI Cost Code Variances Table
CREATE TABLE cost_code_variances (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    csi_code VARCHAR(20) NOT NULL, -- e.g. '03 30 00'
    division_name VARCHAR(100) NOT NULL, -- 'Cast-in-Place Concrete'
    budgeted_amount NUMERIC(15,2) NOT NULL,
    actual_amount NUMERIC(15,2) NOT NULL,
    variance_amount NUMERIC(15,2) GENERATED ALWAYS AS (actual_amount - budgeted_amount) STORED,
    root_cause_summary TEXT,
    is_contingency_absorbed BOOLEAN DEFAULT TRUE
);

5. Backend টিমকে যেভাবে সংক্ষেপে উপস্থাপন করবেন (Quick Presentation Guide in Bengali)

ডেভেলপারদের সাথে আলোচনার মূল বিষয়গুলো:

  1. অনারের মূল চাহিদা: অনার কোনো টুলস বা চেকলিস্ট দেখতে চান না। তিনি দেখেন মোট কত টাকা ইনভেস্ট হয়েছে (Total Budget), কত খরচ হয়েছে (Total Spend), এবং কোম্পানির লাভের জন্য রাখা ইমার্জেন্সি বাফার (Contingency) ঠিক আছে কি না।
  2. লাইভ হেডকাউন্ট (94 on site): ফিল্ড সুপারিনটেনডেন্ট সকালে যে ডেইলি লগ তৈরি করেন, সেখানকার সব সাবকন্ট্রাক্টরের লোকবল যোগ করে স্বয়ংক্রিয়ভাবে অনার ড্যাশবোর্ডে লাইভ দেখানো হয়।
  3. ক্যাপিটাল ব্যালেন্স বার (Paid 48%, Committed 35%, Contingency 17%): ব্যাকএন্ডকে এই ৩টি ফিল্ডের রেশিও এপিআই-এর মাধ্যমে পাঠাতে হবে।
  4. Latti AI ও রিস্ক অডিট: যখনই কোনো কস্ট কোডে বাজেট অতিরিক্ত খরচ হয় (যেমন: ফাউন্ডেশন পাইলিংয়ে +$14,200), তখন ব্যাকএন্ড AI ইঞ্জিন এটি ডিটেক্ট করে অনারকে জানাবে যে টাকাটি কন্টিনজেন্সি রিজার্ভ থেকে কভার হয়েছে কি না।
