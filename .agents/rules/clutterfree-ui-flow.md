# Clutter-Free UI & Microcopy Rules

Enforce these rules across all UI components and views:

1. **Concise Microcopy**:
   - Strip AI filler text ("Seamless", "Comprehensive", "Elevate", "Delve", "Streamlined").
   - Keep button text and labels under 2-3 words (e.g., "+ New Log", "+ Add Task", "Save").

2. **Zero Unnecessary Text & No Redundant Roles**:
   - Eliminate marketing/slogan filler (e.g., "Live chronological field stream", "Select an action for your project").
   - Never embed roles in parentheticals inside names (e.g., avoid "Sarah Johnson (Project Manager)" when subtitle already states role).
   - Avoid dual-unit text that causes truncation (use "82°F" rather than "82°F / 28°C" which truncates to "...").
   - If extensive text is strictly necessary (e.g., structural specs, legal lien details), place it in the detail modal/drawer, NEVER cluttering primary feed cards.

3. **Clutter-Free Card Rule (Max 3-4 Elements)**:
   - Primary Title (Clean name or action)
   - Status/Category Badge
   - Single Date or Metric line
   - Clean summary without redundant subtitle bloat.

4. **User Flow Priority**:
   - Single focal point per screen.
   - Primary action buttons highlighted with `#1677FF`.
   - Secondary details pushed to detail modals/drawers for max scannability.
