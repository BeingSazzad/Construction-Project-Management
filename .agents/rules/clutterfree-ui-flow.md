# Clutter-Free UI & Microcopy Rules

Enforce these rules across all UI components and views:

1. **Concise Microcopy**:
   - Strip AI filler text ("Seamless", "Comprehensive", "Elevate", "Delve").
   - Keep button text and labels under 3-4 words.

2. **Clutter-Free Card Rule (Max 3 Elements)**:
   - Primary Title
   - Status/Priority Badge
   - Single Date or Metric line
   - Remove extra icon boxes, double arrows, or repeated long subtitles.

3. **User Flow Priority**:
   - Single focal point per screen.
   - Primary action buttons highlighted with `#2563EB`.
   - Secondary details pushed to detail modals/drawers for max scannability.
