# Visual Hierarchy Mastery

## 1. Typography Scale Rules

- **Header 1 (Page Title):** `text-base sm:text-lg font-bold text-white tracking-tight`
- **Header 2 (Card Section Title):** `text-sm font-bold text-white tracking-tight`
- **Body Text:** `text-xs font-normal text-slate-200 leading-relaxed`
- **Subtext Metadata:** `text-xs font-medium text-slate-400`
- **Micro Tags / Badges:** `text-[10px] font-bold tracking-wider`

## 2. Spacing & Rhythm

- **Page Container:** `px-5 py-4 pb-28 gap-4 max-w-[430px]`
- **Inside Cards:** `p-4` or `p-3.5`
- **Gap between items:** `gap-2.5` or `gap-3`

## 3. Strict Rules to Prevent Layout Fatigue

- **Rule 1:** No double page titles stacked on top of each other.
- **Rule 2:** No "Good morning" greetings on non-home pages.
- **Rule 3:** No right chevron arrows (`>`) next to status pills on list cards unless necessary.
