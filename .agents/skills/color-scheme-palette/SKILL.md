# Color Scheme & Palette Systems

## Dark Sapphire Construction Theme Tokens

| Token | Hex Value | Usage |
| :--- | :--- | :--- |
| **Canvas Dark** | `#070B14` | Main page background |
| **Card Primary** | `#0D1424` | Grouped cards, input containers |
| **Card Surface** | `#090E1A` | Inset item rows, dark pills |
| **Border Hairline**| `#1A263E` | Card outer strokes |
| **Border Subtle** | `#141F33` | Divider lines |
| **Accent Primary** | `#2563EB` | Primary buttons, active tabs |
| **Accent Highlight**| `#3875F6` | Interactive hover links |

## Backlit Status Dot Badges

- **On Schedule / Success:** `bg-emerald-400` + `bg-emerald-500/10` container + `border-emerald-500/20`
- **At Risk / Warning:** `bg-amber-400` + `bg-amber-500/10` container + `border-amber-500/20`
- **Critical / Delayed:** `bg-rose-400` + `bg-rose-500/10` container + `border-rose-500/20`
- **Planning / Active:** `bg-blue-400` + `bg-blue-500/10` container + `border-blue-500/20`
